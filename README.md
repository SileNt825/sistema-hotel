# sistemaRevervasHotel

Projeto Java para gerenciar reservas de hotel.

Estrutura do projeto:

- application/: classe principal `Program.java`
- models/: entidades do domínio (Hospede, Hotel, Quarto, Reserva)
- enums/: enums auxiliares

Como subir para o GitHub:
1. git init
2. git add .
3. git commit -m "Initial commit"
4. git branch -M main
5. git remote add origin https://github.com/SEU_USUARIO/sistemaRevervasHotel.git
6. git push -u origin main
